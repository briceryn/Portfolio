Infrastructure réseau d'entreprise

Debian DNS Apache LDAP Samba

Mise en place d'un réseau complet avec routage, serveur DNS (BIND9), serveur web (Apache), bases de données (MariaDB/PostgreSQL), annuaire LDAP et partage de fichiers Samba. Sécurisation par iptables.

DSATUR - Coloration de graphe

Java Algorithmes Graphes

Implémentation de l'algorithme DSATUR pour la coloration de grands graphes (Email-Enron : 36692 sommets, 367662 arêtes). Optimisation avec BitSet et PriorityQueue pour des performances optimales.

Détails

Transformée de Fourier rapide

Python FFT Traitement d'images

Implémentation de la FFT 1D et 2D ainsi que leurs versions inverses. Passage d'une complexité O(N⁴) à O(2·N²·log(N)) via l'algorithme diviser pour régner. Application au traitement d'images.

Détails

OpenGL GLUT C++ Textures

Modélisation complète de Pikachu en 3D avec sphères paramétriques, textures JPEG (peau, rayures, fond), éclairage (2 sources lumineuses) et animations (balancement, rotation caméra).
